# App Review screen recording

Generated by `npm run app-review:record` (Silent Hour–style auto-tour + Playwright capture).

| File | Use |
|------|-----|
| `simulator-review-iphone.mov` | iPhone simulator capture (simctl) |
| `simulator-review-iphone.mp4` | Same capture — MP4 for App Store Connect |
| `app-review-recording.mp4` | Playwright web capture (do not attach as device recording) |

**Tour shown (~90s):** Login → Let's go! → Welcome → Dashboard → Mission → Add family member → Journey → Settings → Clear all data → Login again.

**Regenerate:**

```bash
npm run app-review:record
```

On Mac with Xcode, `npm run app-review:record:simulator` uses native iOS Simulator when `scripts/record-app-review-ios-sim.mjs` is present; otherwise falls back to Playwright.

Paste review notes from [docs/FAMILYHUB_APP_STORE_REVIEW_REPLY.md](../docs/FAMILYHUB_APP_STORE_REVIEW_REPLY.md).
